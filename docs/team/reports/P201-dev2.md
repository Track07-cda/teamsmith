## Decisions and deviations

- **窗口线索只在「pane 的会话 = 本项目 `TEAM_SESSION`」时算数**。任务书写的是「窗口名 ∈ 名册 → 拒绝」，
  我加了会话条件：`P82 3.2`（[auto] 路径）早就钉住「别的会话里的同名窗口不是本项目的席位」，同一条运行时
  上下文的两条路（CLI / 扩展）必须同口径；不加这一条，在别的 teamsmith 项目里跑本项目夹具的人会被误拒
  （`p201-foreign-*` 那条反向断言就是它）。**这比任务书更严一点，但方向一致**（线索只否决，绝不署名）。
- **窗口名用 `-t $TMUX_PANE` 问调用者自己那块 pane**（任务书 ① 的字面要求）。实测（第 6 节）：无目标的
  `display-message` 回答的是 attached client 的当前窗口 —— 从 dev2 pane 里问出来 `pm`。夹具只回答
  `-t %4242`，所以「回到无目标形态」这种回归会把 ①② 打红。
- **线索绝不署名**：窗口名是可改的 UI 状态、`TEAM_AGENT` 是继承值（P82 已否决用它们当发送者），所以它们
  只能否决目录的 `pm` 声明；工作树里目录照旧赢，`TEAM_AGENT` 分歧照旧点名。
- **两个 smoke 夹具显式写 `--from pm`**（`12b-d` 的 held 夹具、`12b-pi` 的 knock 夹具）：它们从主检出发
  `notify pm`，假 tmux 却报窗口 `dev`。P201 之后那是「主检出 + 线索」= 拒绝，夹具必须自报发送者。改的是
  夹具的输入，不是断言；两条断言（收件箱有 held body / spool 行 `knock pm pm`）不变。
- **`0c` 的自伤**：新函数以 `[ … ] && [ … ]` 结尾被 0c 拦下（set -e 陷阱），改成 `|| return 1` + 裸 test。

  直接重跑（自建临时仓库 + 私有 shim，不碰真实 tmux）。

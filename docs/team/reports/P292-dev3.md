## 实现自述（便于独立复验时对着源码核）

**对象证明链**（`team_interrupt_identity`）。pid 只能来自该席位派单记录里那个窗口的 pane：先取 pane 的前台进程，
取不到就取「命令行命中本项目配置的 agent 可执行文件」的直接子进程（复用 `team_pane_agent_pid`）。证明用**普查的同一套判据**：
形状沿用 `team_orphan_shape_match`（含 `pm.pid.spawn` / `dispatch-*.spawn` 排除），归属读进程**自己** environ 里的
`TEAM_MAIN_ROOT`（本项目）与 `TEAM_ROOT`（必须等于派单记录的工作树），命令行再命中配置的 agent 可执行文件。
全程没有按名字、父子、进程组选择进程：发信号只写 `kill -TERM/-KILL "$pid"`（`signal-lint.pl` 真树扫描 0 条按名字选进程）。

**计划态与授权**。`--yes` 只从**这次 argv** 上取（`TEAM_YES_ARGV`），不看 `TEAM_CONFIRM_WRITES` / `TEAM_ASSUME_YES` /
任何继承值；没有它就是计划：打印席位、pid、证据（会话最后落盘 + 未提交条数 + 最新磁盘证据与岁数）、将发的信号、
理由与回来的路，零信号、零写盘、退 0；目标不可打断的计划退非 0 并给出路。

**复验（发信号之前）**。同一 pid 再证一遍四件事：窗口还在、pane 里的 agent 进程仍是这个 pid、身份仍成立、
进程启动时刻与计划读到的那个值一致。任何一条不成立 → 拒发、点名理由（窗口没了 / 已经不是计划时那个 pid /
启动时刻不一致（pid 可能被回收）/ 身份变了）、退非 0，且**线程、收件箱、审计一个字节都不动**（理由投递在复验之后）。

**信号与审计**。`SIGTERM` → 有界等待（默认 5s，`TEAM_INTERRUPT_GRACE_SEC` 可调，非数字退回默认）→ 仍活着再 `SIGKILL`；
僵尸（`/proc/<pid>/stat` 状态 `Z`）算**已结束**——它收不到信号、也不占回合，把它算活着会把成功的打断写成假红。
授权的一次打断恰好一行审计（时间戳 / actor / 席位 / pid / 理由 / 打断前会话落盘时间 / 打断前未提交条数 / guard /
信号序列 / 结果），写进 `state/interrupt.log`；actor 从运行时目录解析，解析不出来 → 拒发且什么都不写。

**理由先写、后发信号**。线程（`threads/<seat>.md`，席位阅读顺序的第二步）与收件箱两处；**写不进去就拒发**
（见下面那条真缺陷）。理由里的换行与控制字符折叠成一行——审计行的形状是固定的。

**新鲜窗口**。席位自己的磁盘证据 = 派单记录里那个 sid 的会话文件（`team_session_file`，位置接缝仍走 `TEAM_PI_AGENT_DIR`）
+ 工作树里 git 报为改动/未跟踪的文件的 mtime（`status --porcelain -z --untracked-files=all`，`-z` 按原始字节读，
重命名/复制的第二段跳过）。两份里最新的比窗口（默认 3600s，`TEAM_INTERRUPT_FRESH_SEC`）新 → 拒绝并点名
「哪个文件 + 多少秒前 + 窗口多少秒」；`--force` 才越过，越权写进审计 `guard=forced`。缺证据（两份都读不到）放行——
那是 D188 的形状，也是本入口存在的理由。

**与既有入口的分工**（既有语义一个字没改）。没有在跑的回合 → `team resume --agent <seat>`；窗口没了而进程还在（孤儿）
→ `team reap --orphans`；不在名册 → 名册；调用者自己或它的祖先 → 拒发（`--force` 也越不过）。本入口**不碰窗口**：
它结束回合，窗口留给 `resume` 按自己的路径替换。

**跨项目零点名**。别的项目的进程只产出「身份属于**别的项目** —— 拒发」这一句：它的项目名、席位名、工作树、pid
一个都不打印（夹具逐条断言输出里不含 `other-proj` 与那个 pid）。这条不只是隐私——这份读数会被抄进公开账本。

## 真缺陷与翻转证据（红 → 绿）

夹具逮住一个**真缺陷**（不是造出来的红侧）：

- 现场：把席位的线程文件换成一个目录（写不进去的确定性形状），再跑授权打断。
- 红：原实现把线程追加写成 `if ! { …; } >> "$thread_file" 2>/dev/null; then …`。bash 对**复合命令的重定向失败**
  在 `!` 位上状态不可见（实测：同一形状 `rc=1` 但 `if !` 走 `else`），于是「写不进去」被当成写成功 —— 信号照发，
  席位被杀却读不到任何理由，正是合同禁止的「杀了它，但它不知道为什么」。
- 绿：抽成独立的 `team_interrupt_thread_append`（`{ …; } >> "$f" 2>/dev/null || return 1`），并顺手让审计写失败
  大声报错、退非 0（动作已做但**没有记录可查**）。同一现场现在是：拒发、点名「写不进该席位的线程」、进程仍活着、
  审计与收件箱一个字节不动（`reason` 组 5 条断言）。
- 逐条红侧里也有这一条的守卫：`p292-flip-reason-order` 把理由投递改成延迟（TERM 时线程里还没有）→ 指定用例必红。

`if !` 那条的完整红侧转换（修复前）：`测试线程写不进去 → 拒绝：期望不等于 [0]`、`线程写不进去 → 一个信号都没发`
（进程已不在）、`线程写不进去 → 审计不增长：期望 [1] 实际 [2]`；修复后同一组 5 条全绿。

## 收尾清理：夹具不许留下自己的根（PM 2026-10-16 的提醒，已修）

PM 在 `/tmp` 里数到 **34 个** `teamsmith-seat-interrupt.*`、约 **1.6 GB**。已定位、已修、已清。

**根因（我自己的缺陷）**：夹具在 `tmp_root_create` 之后写了 `export TMPDIR="$TMP/tmp"`。
`tmp-root.sh` 的 run 台账与回收**都按「创建时的 `${TMPDIR:-/tmp}`」算**（台账路径 = `<基>/.teamsmith-tmp-ledger.<run>`）：
中途改基之后，`tmp_root_reap_all` 到**新基**去找自己的台账，找不到就静默返回 —— 什么都不收。
隔离探针已把这个因果链坐实（建根 → 改 TMPDIR → 回收：台账留在旧基、根留下；不改 TMPDIR 则回收干净）。

**第二处（让清扫器也收不掉被杀的轮次）**：`touch` 模式的 stub 把会话文件摸成 `@1799999999`（远期）。
`tmp-hygiene --sweep` 的年龄按根内**最新 mtime** 算，远期 mtime 让年龄变成负数、根永远“太新”不被收。
改成「摸成现在」（对审计断言的语义不变：仍然晚于打断前那个 1700000000 的读数，且大小关系可断言）。

**修法三条**（提交 `f467bfb1`）：① 自己的 shell 不再动 `TMPDIR`，只给**子进程**传私有 `TMPDIR`（`OC_CHILD_TMPDIR`，
API 调用、stub 席位、变异片段都走它）；② 收尾自检：`cleanup` 里 `tmp_root_reap_all` 之后根还在就**大声报错并退非 0**
（静默泄漏是实缺陷，不是小事）；③ `touch` stub 改成摸成现在（同上）。

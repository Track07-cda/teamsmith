## §7 · 门禁里那条红是既有的：§36⑧ 的牙齿被 P162 的 `tmux()` 包装吃掉（P148×P162 交互）

**形状**：`checkout-shape-probe.sh` 的 ⑨ 牙齿一 —— 建一棵产品面 scratch 树、往
`skills/teamsmith/tests/tmp-hygiene.sh` 里追加一行裸 `tmux kill-server`、跑 `--select 31`，**要求 §31 变红**。
现在 §31 绿。

**机制（实测，`logs/20-mechanism.txt`）**：`tmux-lint.pl` 的 `collect_wrappers` 把「函数体里碰了 tmux」的
函数登记为**目录级**包装（`$WRAP_DIR{dirname(file)}{name}`）；`wrapper_iso(file,'tmux')` 于是对同目录下
**任何文件**里的裸 `tmux` 调用返回 1（= 已隔离）。P162（`9071c36d`）在 `skills/teamsmith/tests/smoke.sh`
里定义了 `tmux()` 包装（`env -u TMUX -u TMUX_PANE TMUX_TMPDIR=…` → `iso=1`），于是 `tests/` 下所有文件的裸
调用都被判成「调用了隔离包装」。同一棵树的副本上做对照：包装在位 → 种下的那行是 `ok`；**只把包装改名** →
同一行变 `RED`。

**归因**：P148（`251c5e45`，14:26）把探针与这条牙齿带进 main，P162（`9071c36d`）在它之前（13:4x）已经
在 main 上 —— 两个变更各自绿、相遇就红。三个 ref 的同一实验（`git archive` 各自的树 → 种同一行 → 各树
自己的 lint）：`aa787487`（P159 合并，无包装）= 1 条红（牙齿成立）；`bbe634af`（本轮分叉点）= 干净；
`main` = 干净。把 **main 的干净快照**交给探针本身（容器内）：`ok 71 bad 1`，bad 就是同一条。

**结论**：与 P169 无关；它挡住的是**全量门禁**（§36 在 FAST 与全量里都跑）。修它属于 M28 lint 的语义
（包装登记的作用域：按目录 / 按文件 / 只认 `tests/lib/**` 里的共享包装；或者把 `tmux` 这个名字排除出
目录级登记，因为它就是二进制自己的名字）—— 需要它自己的任务与红侧，我没有夹带进 P169。

**建议的下一手**：PM 另开一条（P162 那条线的 owner 更合适），改动面 `skills/teamsmith/tests/tmux-lint.pl`
+ 它的 `--selftest`/翻转夹具，验收至少包含：`checkout-shape-probe.sh` 全绿（71 ok / 0 bad）且真树的

## Decisions and deviations

1. **非平坦 id 的退出码**：任务书只说「必须拒」，没定码。取 **2**（用法：id 没有路径语义），与既有契约
   「2 = 用法」一致；软链/非正规记录仍走 4（记录畸形）。spec 里写明了这两档。
2. **补上 pgid 一致性核对**：任务书写「已有」，实际没有（见「现场与判定」）。现在发信号前要求活进程当前
   进程组 == 记录的 `pgid`，不等 → 5；这也关掉「记录的组号被别的进程组复用后误发组信号」的口子。
3. **新增 `--break=no-boundary` 红侧**：任务书没要求，但它是这套断言的证伪面（短路解析器 → 11 条红），
   也让 PM 复验不用翻 git 历史；与既有 `--break=no-identity` 同形。
4. **spec/design 增量**：边界是「必须成立」的规则，按 AGENTS 的纪律写进了 `safe-signal-discipline` 的
   delta（RA3 的 MODIFIED + 两条 scenario；D6 补一句），没有另起规格。
5. **`tasks.md` 勾选口径**：24/24 按交付勾，尾部「Apply status」写明证据来源；没有把 P159/P166 的
   证据冒充成本轮重跑，也没有为了好看把没验的项写成「已验证」。
6. **工作树卫生（lint 扫忽略文件）**：`signal-lint.pl` 的默认扫描面含 `docs/team/reports/*/pkg/**` 的
   **全部文件**（含 gitignore 的 scratch），我的工作树里留着 P52 的 `pkg/out/scratch/`
   （`.gitignore` 明确排除、内含一条历史 `pkill -f`），它让真树 lint 在我这里先红。我把它移到
   `/tmp/p169-moved-ignored/P52-dev2-out-scratch/`（**没有删**，需要可搬回），此后真树 lint 绿。
   这是工作树本地卫生问题，不是仓库内容问题（全新检出/复验 worktree 没有它）。
7. **门禁在容器里跑**（PM 的临时纪律）：`--select 58` 与 FAST 都经 `pkg/ct.sh` 在
   `localhost/teamsmith-gate:local` 里跑，容器有自己的 /tmp 与 tmux server；宿主上只跑了不碰 tmux 的
   夹具/lint/渲染/只读检查。

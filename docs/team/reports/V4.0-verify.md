# V4.0 · Adversarial verification of the core lifecycle (teamsmith)

```
task:   V4.0      agent: verify
pin:    cd8bdb9   verified revision = cd8bdb9 (skills/** byte-identical; see §4.3)
branch: task/V4.0-core-lifecycle (local mode — not pushed; PM merges after re-verification)
result: package exit 0 on two consecutive runs · 178 assertions ✓ / 0 ✗ · 29 findings · smoke 486 ✓ / 0 ✗
```

**Mission was falsification.** Everything below came out of running commands, not out of reading code. The package
lives in `docs/team/reports/V4.0/pkg/` and is re-runnable from a clean checkout of the pin:

```sh
bash docs/team/reports/V4.0/pkg/run.sh                 # ~110 s, exit 0 = every section ran without script-level ✗
bash docs/team/reports/V4.0/pkg/run.sh --flip-only     # just the red→green flips
V40_KEEP=1 bash docs/team/reports/V4.0/pkg/run.sh      # keep the scratch dir
```

Every experiment runs in `/tmp` scratch repos. All tmux traffic the tool makes is forced onto a **private server
socket** by a PATH shim (`v40pkg-$$`), so even `-t ""` cannot reach another session; the package proves the repo is
untouched with a before/after `git status`.

Logs: `docs/team/reports/V4.0/logs/sections/*.log` (per section), `logs/run.log` + `logs/run-repeat.log` (two
consecutive green runs), `logs/smoke-full.log` (project gate).

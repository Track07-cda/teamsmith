## 结论

一句话：**18 个夹具无执行路径，其中 13 个守着点名过的事故**（另 5 个守契约面或工具面）；再加
`tests/lib/tmp-root.sh` 的 `--self-test` 入口同样没人跑，一共 19 个。分母是 `skills/teamsmith/tests/*.sh`
的 64 个文件（46 个有根 + 18 个无根，无遗漏、无重复）。

`panel-b3.sh` 不是唯一一个，但它是最贵的那个：整块控制台 pty 面（分页 / 队列 / 设置 / resize / 语言 /
SGR 鼠标 / q 折叠）今天没有活守门人，而 §28 只覆盖 headless 那一半。

另一个比「没人跑」更坏的性质：13 个 `flip-*.sh` 里 **7 个在修复落地后结构上就跑不起来**——它们的红树取
`merge-base HEAD main`，一旦修复进了 main，这个基点就是修复后的树，夹具会自己拒绝（实测见 §证据）。

## 2 排序与建议

按「守的东西有多贵」排，同档内按「今天有没有活守门人」排：

1. **`panel-b3.sh`** —— 唯一一个既贵又没有活守门人的：整块 pty 面（鼠标 / resize / 折叠 / 分页）在 §28 里
   一个都没有对应断言，而它是红的。建议接线，但等 behavior-focused-ci 把 8 条夹具假设修完；接线时只折
   「§28 覆盖不到」的那几个场景，并换 `lib/pty-wait.sh` 的有界等待（不是 `sleep` 改数字）。
2. **7 个 merge-base 翻转**（`flip-m4.3` / `m43` / `m45` / `m46` / `m7.2` / `p25` / `p71`）—— 守的事故最贵，
   但**结构上不可重跑**：红树取 `merge-base HEAD main`，修复一旦进 main，基点就是修复后的树。它们不是
   「忘接线」，是「接不了线」。建议删掉，红→绿证据留在当时的报告里；对应行为今天都有活守门人（见 1.1 表）。
3. **6 个可重跑、且同行为已有活守门人的翻转**（`flip-m33` / `m44` / `p72` / `p308` / `p171` / `p287-lock`）——
   它们证的是「那条断言真的会咬人」。这一层证据有价值，但代价是每轮多跑两到三棵树。建议：能折成一两个
   变异（像 §58 的 `--break`、§38-a 的 F-A/F-D）就折，折不动就删；不要整份夹具接进门禁。
4. **契约面/设计面，部分有活守门人**：`panel-flip-m54`（§38 已守，删）、`panel-keyprobe`
   （无守门人，删并记账）、`panel-keyprobe-stub` 随 `panel-keyprobe` 一起处置。
5. **工具面**：`section-needs-audit` 与 `lib/tmp-root.sh --self-test` —— 保留但不接，在表里标明「人工入口」，
   免得下次又被当成守卫。

一句话的取舍原则：**翻转夹具是一次性的红→绿证词，不是长期守卫**。长期守卫应当是门禁段里的一条断言
（最好自带一个便宜的变异），这样它每轮都跑、坏了当场红。今天 13 个 `flip-*.sh` 里有 7 个连「一次性」都做不到了。

## 3 `--select` 映射表里的「有归属但没人跑」

答案是 **2 行**，而且这两行是 catch-all：

- `12b-h0d`（P80 下边框判据）与 `40`（临时根纪律）的 patterns 里都有 `skills/teamsmith/tests/*`。
  该 glob 按 bash `case` 语义跨 `/`，于是**任何**测试夹具的改动都会选中这两段。
- 这两段实际执行的夹具各只有 **1 个**：`12b-h0d` 跑 `pm-box-real.sh`，`40` 跑 `tmp-hygiene.sh`。
- 结果：18 个无执行路径的夹具全部「有归属」（都落在上面两行），**没有任何一行按名字声明它们**。
  每一行各有 63 个「声称拥有、但自己不跑」的夹具（64 − 1），两行合计 126 个蒙对的归属关系；
  其中 18 个是「全树都没人跑」，其余是「别的段在跑、这一行只是重复」。

这与任务书的判断一致但机制要说清：`panel-b3` 不是被某一行点名后没人跑，而是被两个 catch-all 顺手收编。
所以「有归属但没人跑」的假象不是个别行写错，而是 catch-all 的固有代价——它让「改了夹具就有人管」成立，
但也让「改了夹具就有人跑」看起来成立。若要让这一格有意义，两行里至少应有一行**在执行它拥有的夹具**，
或者把 catch-all 收窄成显式清单。

## 2. 判定规则（本表的「留 / 拿掉 / 待定」怎么定的）

任务书的规则 + 边界那一段是判据；落到可操作的四条：

1. **留（逻辑类）**：断言的成功与否由**行为 / 状态**决定，与措辞无关——退出码、副作用（写了哪个文件、起了哪个进程、窗口在不在）、拒绝是否发生、状态是否恢复、计数、字节 / 哈希一致、JSON / `--print` / `--help` 的**机读字段**、审计行、argv 透传；以及**针是机器 token** 的「承诺兑现」类（命令、旗标、路径、占位符、字段名、spec 条目 id、本次运行实测出来的值）。
2. **拿掉（文本类）**：断言的**主体就是文本本身**——一句提示 / 文案 / 报错 / 提示词必须含哪些词、必须不含哪些词；排版（缩进、行宽、列计划、对齐、帧高、逐字节快照）；语言（必须英文、不许 CJK、两套语言表键集相等、en 表某句文案）；术语与概念呈现（分节线标题、徽章词、图例、口径说明句）；以及**用这些文案当定位针**去「找到那一行」的夹具写法。
3. **待定（列给 PM 裁）**：断言的**标签说的是行为**，但**唯一证据是散文**（诊断整句、状态词、术语 + 计数），删掉就丢了那条行为的唯一观测；或一条断言里**混了**两类（顺序留、排版删）。这些行在表 B 里给出**两种读法**与我的建议，但**没有自行归类为拿掉**。
4. **不判**的两种形状（本表一律按「留」处理，但单列在 §5）：
   - **代理行为**：表面查一串字、实际代理一个事件 / 状态（任务书边界里点名的形状，例如「渲染出的简报里含通知段」代理「简报真的送到席位」）。
   - **源码形状钉子**（「静态钉子」）：钉的是实现里的某个调用 / 字面量（例如 `rmSync(marker, { force: true })`、`[ "${a[$end]}" != ";" ]`）。它既不是措辞 / 排版 / 语言，也不是用户可观察行为——属 D170 未覆盖的第三族，本表不改动它，另在 §5 点名。
5. **不削弱**：本表不含「把断言改宽松」的选项——每条非「留」项要么**删**（守护的行为另有断言或改由评审把关），要么**待定**。没有任何一条是「保留但放松」。

### 1.1 分片的语义

```
$ slice_of_key() { … c="$(key_crc "$k")"; printf '%s' "$(( c % n ))"; }   # 基线下标显式传入但**不参与**
$ bash skills/teamsmith/tests/section-select.sh --floor --slice 1/4 | sed -n '1,6p'
decision=RUN
sections=135
slice=1/4
base=floor
own=35
borrowed=10
```

- `own` = 基线里哈希落进本片的 key；`borrowed` = 为 `needs`/耦合组从别片借来、**照跑**的段。
- 给了 `--out` 时另写 `<out>.keys`（own、源序、每行一个 key）；借来的不在里面。
- 兜底的「全套」（未声明路径 / 基点不可解析）在切片模式下也按片切（`base=all`）——否则矩阵每一片都要跑整套。
- 组合规则：`--slice` 与 `--floor` / `--paths` / 不带决策同用；与 `--select` / `--check` / `--list` 同用一律 rc=2
  （显式选集与「从基线切一份」是两个决定，混用时「第 k 片」没有唯一所指）。


## 三项的处置与证据

### 1 · F1′：收口按段数判

改动（`tmux-identity-leak.sh`）：`selects()` 之后新增段数账 —— `TMUX_SEL` = 本轮**选中**且需要 tmux 的段数
（`write-side session-scope kill-identity residue guard-kept doctor` 六个），`TMUX_RAN` 由 `seg_ran` 在六处
`else` 的第一行累加；收口改成：

```bash
if [ "$TMUX_RAN" -eq 0 ] && [ "$TMUX_SEL" -gt 0 ]; then … exit 77; fi
```

为什么不是「所有段都没跑就 77」的一句话版本：**④（审计）不需要 tmux**（它只用 stub + shim），在假 tmux 现场它照样跑
并给出 6 条 ✓ —— 这正是「✓ 8」里的大部分。若把「跑过」算上 ④，假 tmux 现场仍然不是全跳过，判据还是抓不到；
反过来 `--select audit` 这种合法单跑又必须 rc=0。所以「跑过」只认需要 tmux 的段。⓪ 是前提探针（不是被测的段），
不计入。`TMUX_SEL=0`（只选 `audit`）时收口照旧按该段的 pass/fail 判。

附带的准确性修正：`TMUX_WHY` 原来只有「没有 tmux」一种措辞，`-V` 失败时也照抄，于是收口行写着「没有 tmux」而实际
是「有但不能用」；现在两条分支各自给原因（上面前后的收口行对比可见）。

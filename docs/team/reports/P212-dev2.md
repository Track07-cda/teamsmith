## Decisions and deviations

- **退出码 0/1/3/4**：`0` 全查过且干净 · `3` 干净但有子项被跳过（名单缺失/为空、用户名解析不出——**不是通过**）·
  `1` 有命中 · `4` 扫描器自身出错。用 `3` 而不是 `0` 是刻意的：把「查不了」与「查过且干净」分开。
- **真树只看会被提交的那部分**：`git ls-files -c -o --exclude-standard -- docs/team`（1217 个 `.md`）；
  被忽略的证据层（`docs/team/reports/<ID>-<agent>/…`）不进公开面，不扫。`--all` 退回目录 glob，只给夹具用。
- **名单路径**：`.pi/team/forbidden-names.txt`（一行一个，`#` 注释，整词 + 大小写不敏感）。它在 `.pi/` 下 ——
  已被忽略，名单本身不会随仓库公开；缺失/为空/读不了都是可见 SKIP。
- **awk 动态正则的坑（实测，写进了注释与 §9b-3）**：`awk -v re='\\.'` 在 mawk 上会把 `\.` 吃成「任意字符」，
  于是 `10. §6g`、`timeout10.log` 全假红；含区间的「多分支择一」在 `~` 与 `match()` 上还会不一致。
  对策：点一律写 `[.]`、量词写 `[0-9][0-9]?[0-9]?`、检测一律用 `match()`。
- **夹具旋钮**：`--user` 只在 `TEAM_SMOKE_FIXTURE=1` 下生效，非夹具路径传它会被忽略并打印一行 —— 环境不能
  悄悄把边界拆掉（与本仓库既有的 panel 旋钮规则同源）。
- 与 brief 的差异：无。brief 的 5 条（扫描器 / 可证伪 / FAST 接入 + 名单缺失记 SKIP / 门禁 + 复验换人）逐条对上。

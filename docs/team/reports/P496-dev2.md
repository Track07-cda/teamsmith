agent: dev2 · status: DELIVERED (proposal only) · time: 2026-11-25T01:54Z

**建议：用 `team board label` 定义、贴上和移除项目标签，在 Pulse 看板用“标签”和“排序”查看结果。** 普通看板仍按状态分栏，历史从最近一批看起；只有明确选择“优先级”才按各标签分数之和在栏内重排，同分仍按原看板顺序。在原有任务详情查看标签和分数，没建任务书也能用；标签不占卡片标题的位置。任务表里同一个 ID 的两张卡共用标签，但仍各自可选；表外同 ID 的行仍照旧显示，不继承标签。

**保留旧用法，只替换容易漏错的检查。** `board ls` 无选项不读标签，Markdown、列数和旧命令不变；首次定义才在看板旁创建一份标签文件。计划把旧检查的“新行出现 ID”换成七列及未改列的比较，把“59 列出现标题片段”换成同一卡片有无标签的整行文字比较；原有重复 ID 拒绝、警告、卡片导航、历史窗口、滚动和宽度检查保留。排序检查直接读 T2 的分数：3 和 5 相加是 8，误取最大值时是 5；首轮任务顺序两种算法相同，不能据此判断。上述是未来实施后的验收设计，不是本轮已运行的行为结果。

## 判据（做了什么）

- **记什么**：`HEAD` 全 sha + `git --no-optional-locks … -c status.renames=false status --porcelain
  --untracked-files=all` 输出的 sha256（**含未跟踪**；`--no-optional-locks` 只读、不抢索引锁；
  `renames=false` 把「重命名怎么显示」钉死）。现场文件里同时留 `status_cmd`、开跑/收尾时间戳与逐行判定。
- **口径 = 整棵树**，不追「门禁读了哪些文件」：便宜、无歧义，方向保守 —— 跑动中改的是门禁**没读过**的
  `docs/team/**` 记录，也照样算「树被改了」（夹具用例③就是这条口径的可执行证明：0d 段自测明说不扫未跟踪
  文件，门禁确实没读过那个路径）。
- **一致**：一个字节都不多打（新增的字节全在本轮根里的现场文件；结束用量行的文件数因此 +1，那是它的本职）。
- **不一致**：判词两行，在结果行**之前**；`✓/✗` 照旧打印（不吞）；收口退出码 **4** —— 0 绿 / 1 有失败项 /
  2 门禁自己停跑 / 3 建不出临时根 / **4 本次运行无效**，五个码不重叠（写进 `references/protocol.md` §9b-2）。
- **不是 git 检出**（产品面安装树）：打印一行可见的「运行指纹不可用」并把判定置为不可用，**不判**
  「树被改动」—— 门禁不许对自己没判的事假装判过（P148 同一条纪律）。套件里 `0i` 段在这种树上也**可见
  跳过**，不把「本节判不了」报成红。

## Decisions and deviations

1. **口径取整棵树**（任务书给的取舍里选了「保守、便宜、无歧义」）：不追读集；代价是「跑动中改一条门禁
   没读的记录也判无效」—— 这正是想要的方向（假绿比假红更贵）。用例②③把这条口径变成可执行的证明。
2. **退出码选 4**（任务书允许 3 或 4）：3 已经被「建不出临时根」占用，所以无效用新码 **4**，并把五个码
   的分工写进 `references/protocol.md` §9b-2 与 `references/troubleshooting.md` §25。
3. **不是 git 检出 → 不作判定**（可见提示 + `unavailable`）：不把「读不到」当「没发生」。精确地说：是
   「不判」，不是「判绿」—— 判词不出，退出码照旧由真正跑出来的 ✓/✗ 决定。这条腿没有进套件（它只出现在
   产品面安装树里，而套件自己总在 git 检出里跑），用直接探针留证；套件里 `0i` 段对那种树**可见跳过**。
4. **判词与红并存**：无效时不吞已跑出的 ✓/✗（任务书逐字要求），所以判词在结果行**之前**、收口在结果行
   之后；此时「smoke 全绿 / 有失败项」那两行**不再打印**（它们是「判定」的话术，而这一轮没有判定）。
5. **套件里的 `0i` 段**：它只跑夹具（真树零改动），夹具自己起一次真门禁运行（变体树 + 私有 `TMPDIR` +
   `--select 0b`），所以它同时是「判据在套件里被钉住」与「这条判据能证伪」两件事。
6. **已知边角（没做，写在这里）**：如果调用者把 `TMPDIR` 设在**被判定那棵树里面**，本轮自己的临时根会
   出现在 `git status` 里 → 会被判成「树被改动」（假无效）。本仓库的纪律本来就是临时根走 `${TMPDIR:-/tmp}`，
   任务书的口径也是整棵树的 `git status`，所以这里不做特殊排除（要排除就得按 `$TMP` 的相对路径过滤状态行，
   属于另一条设计）。
7. **成本**：`0i` 段 15s（容器、loadavg≈1.4；段内真跑两次夹具）。已按实测写进预算表
   （band=container、15s、budget=60s=floor）。

## Required fix

1. A `spec.md` symlink (or a `specs/` root link) whose target **resolves outside the change's `specs/` tree** is a
   named defect: one line `<file>:<line>: delta-symlink-escape: <detail>` (add the code to the change's requirement
   list), exit 1. That matches the archiver (it refuses) and keeps parity; it is **not** stricter than the archiver.
2. Correct the false premise wherever it was written: the checker's top comment and your report's §3. The honest
   statement is: *validate does not see this shape; the gate refuses it directly; the archiver refuses it with its
   path guard.* Links inside the tree keep today's behaviour (found, parsed, checked — V2's shape).
3. Red fixtures: an absolute escape and a relative escape (`../../…`), each → rc=1 with the code. Green controls:
   the in-tree legit symlink stays rc=0; a symlink whose target is missing/broken stays out (archiver ignores it) —
   decide and state which, with the archiver's behaviour as the reference.
4. Re-run V2's matrix and your 14-shape symlink harness; report the diffs against the previous tables.

3. **那一页的说明真的渲染出来**：自己起一个私有实例或跑面板夹具取证——那一行的文案里**含自测题**、且在**窄宽度下**问题与「谁发布」都还可见（作者报了把问题放句首，你核它真的成立）。

5. **门禁只有两类**（D170）：存在性 + 行为；若你发现它顺手锁了**措辞**，记一条观察。

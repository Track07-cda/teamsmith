## 必须自己做的（不许只复跑作者脚本）

1. **父进程死亡现场**（核心）：起一个心跳循环（用修改后的写法），**结束它的父进程** → 心跳必须在**短时间**内自己退出（不许等到超时）；再**发 TERM** → 也必须退出（不许 `trap "" TERM`）。
   **红侧**：① 把 `kill -0 "$PPID"` 那一轮检查去掉 → 必须**复现**「父进程没了它还在」；② 把 `trap "" TERM` 放回去 → 必须红。
2. **清扫器两个方向**：① 让一个进程持有**已删除**的临时根文件 → `--status` 的「已删除但仍被持有」读数 **> 0** 且给出合计字节与进程数；② 没有这种持有时 → 必须 **0**（不许把活文件算进去）。
3. **不许按名字动手**：`--sweep` 对这种进程只能**给出计划**（点名 pid + 内存 + 目标路径），**不带确认一个信号都不发**；用它自己的夹具证明「不带确认时没有任何进程被杀」。
4. **同族排查**：核作者列出的 `while :` / `trap "" TERM` 清单是**完整**的（自己全树 grep 一遍比对）；漏一处 → 记 FAIL 并点名。

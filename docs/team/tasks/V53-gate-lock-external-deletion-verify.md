## 必须自己做的（不许只复跑作者脚本）

1. **自己造删除现场**（核心）：让一个门禁运行**持有锁**（在**你的**私有临时目录里跑一个真实段），然后在另一个进程里执行**别的项目会执行的那条清理**——`rm -rf /tmp/teamsmith-smoke.*`（只碰经典名字，不碰点开头的伴生文件）。要求：① 运行中的持有者**察觉**到；② 打印**一行点名**（哪个文件、哪次运行）；③ 在**安全点**停跑（复用既有哨兵退出码，**不新增**判定标记/退出码）；④ 证据**写到工作根之外**、现场保留；⑤ **绝不报通过**。
2. **兼容声明真的生效**：造一个「旧版写入者」（直接持有**原锁文件**）→ 新版运行必须**仍与它互斥**（升级窗口里不许出现静默并发）；反向亦然。
3. **不误报**：造「一切正常的运行」→ **不许**出现「锁被删/被换」的告警（至少跨越一次探测窗口，用你能接受的最短窗口）；单层运行的排队语义、嵌套运行的预算约束、`kind=` 与等待者归因**不回退**。
4. **性能锁同族**：跑一次性能套件（短档）→ 确认它用的是同一实现、且被删时同样**可见地停**（不是静默给出错误测量）。
5. **红侧自己造**：① 把「察觉」那段去掉 → 上面第 1 条的现场必须**不再**被点名（说明它真在守）；② 把伴生锁改回经典名字 → 第 1 条现场必须让**两个运行同时以为自己独占**（你能观察到并发）——即证明伴生名字是**承重**的。
6. **既有绿面不回退**：P281 的四条（记录可归因 / 嵌套受祖辈预算 / 运行时不看时钟 / 写权不可继承）在受检树上各抽一条重跑。
7. 计时类判据按 **D192**；容器里先 `mkdir -p` 再设 `TMPDIR`（D189）；跑前跑后 `/tmp` 根数；**不要**在共享默认服务上做删除实验（用你自己的私有 TMPDIR 与私有 socket）。

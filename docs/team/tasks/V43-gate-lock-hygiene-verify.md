## 必须自己做的（不许只复跑作者脚本）

1. **自己造一个嵌套持有现场**：写一个「父运行持锁 → 子进程在 fixture 里再调 smoke/select」的场景，断言等待者一行里点名 `kind=nested`、所属席位、工作树、**已跑时长**与**上限**；把 `kind` 改成 `top` 或把时长写错 → 必须红并点名（这不是措辞断言，是**归因信息**）。
2. **嵌套预算**：让一个嵌套运行超它生它的那一段的预算（例如 3s 期限 + 永不返回的段）→ 一行点名（段号 + id + 预算 + 实际）、**停下并离开现场**、注册记录消失；**不许**无声占着（这是本变更要治的原始事故）。
3. **父祖证明**：造三种形状各一例——① 真嵌套（能沿进程树走到记录的持有者）→ 不排队；② **伪造的环境标记**（fixture 想自己声明「我是嵌套的」）而进程树证不出 → 必须**照旧排队**（这是「不排队不是自由通行证」的关键红侧）；③ 记录里的 pid 已死/被复用 → 照旧排队。
4. **单层回归**：普通（非嵌套）运行的排队语义不变——两个运行，后到的等，前一个结束了它才开始；`TEAM_SMOKE_LOCK_WAIT` 的超时文案仍点名持有者与等待上限。
5. **只对自己注册的 pid 发信号**：造一个「名字像但不是注册的那个 pid」的进程 → 不许被信号（对应 2026-10-15 那次「按名字选进程」的事故）。
6. **残余窗口可见**：走 `TEAM_SMOKE_NO_LOCK=1` / fast 模式时，记录要**标出**这个窗口；文档（`references/protocol.md` §9b-2）要写明这条纪律。
7. **不削弱**：锁本身不许被去掉；夹具用真 tmux 私有 socket、跑前看 `/tmp` 余量；任何「既有红」同命令对照 **v0.2.0（tag）**。

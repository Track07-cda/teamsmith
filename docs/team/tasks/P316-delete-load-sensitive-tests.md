## 追加判据（用户第二条，2026-10-19）——**性能只能是参考，不能阻塞**

> 「这种性能只能作为参考的指标，不能作为阻塞。」

- **测量可以留**：帧时、段落用时、CPU 占用、刷新间隔——**照旧打印出来**（人要看得见），但**行前面不是 `✓`/`✗`，而是 `·`（参考）**；
- **判定一律不看时间**：任何 `assert 用时 < X`、`assert 在 N 秒内`、`assert 帧 ≤ 2000ms`、`band/budget` 的**红**都要删；保留的只有**防死等**的上限，且它超时时报「**没等到 X**」（附最后一次状态），**不是一个失败的时间断言**；
- **段落超时停跑**这个机制本身改成：**记录**「该段走了 N 秒」+ 继续跑 / 或只在**极端**上限（例如 30 分钟，明显是挂死）时停，并且**它的红只说明「挂住」，不说明「慢」**；
- 一句话：**门禁的绿/红只由行为决定；时间只说给人听。**

## 必须自己做的（不许只复跑作者脚本）

1. **自己造一个「真在跑的长回合」替身**：一个带**本项目身份**（`TEAM_MAIN_ROOT`/`TEAM_PROJECT`/`TEAM_SESSION`）、有**窗口**、有**记录**、正在**反复跑命令**的进程。用它验：
   - `--print`/计划态：**一个信号都不发**、点名 pid 与证据；
   - 授权打断：**只对那一个 pid** 发信号；**审计恰好一行**，且 `session_last`/`uncommitted` 是**发信号之前**读的那一份；
   - **对象不再是那个进程**（pid 复用）：**拒绝、不发信号**；
   - **正在写盘的席位**（新近落盘/未提交变更）：**拒绝并点名证据**；`--force` + 理由可越过且审计记 `forced`；
   - **理由落在席位的阅读顺序**（收件箱/线程里真能读到）；
   - **工作树逐字节不变**（打断前后比一次全树哈希）。
2. **红侧自己造**：① 把「只对一个 pid 发信号」改成按名字/按父子 → 必须红；② 把审计里的 pre-signal 读数改成 post-signal 读 → 必须红；③ 把「理由投递」延迟到信号之后 → 必须红（作者有 `p292-flip-reason-order`，你自己再写一版）。
3. **两处特别检查**：① **跨项目/非本队席位 → 拒绝**并给出该走的路；② **读命令（`status` 等）永不结束回合**。
4. **收尾清理**：夹具跑完**不许留下临时根**（作者说做了；你自己数一遍跑前跑后的 `/tmp` 根数）。
5. **计时类判据按 D192**：当前整机 loadavg 可能远超门禁前提（0.75×核数）——若如此，**计时读数不作判据**，判定看断言与 rc，并在报告里写明当时的负载。
6. 容器纪律：`mkdir -p` 后再设 `TMPDIR`（D189）；任何「既有红」同命令对照 **v0.2.0（tag）**。

## 现场（PM 2026-10-17 实测）

```
/tmp      tmpfs   15G   已用 12G   可用 3.4G     ← 内存盘：夹具写盘 = 吃内存
/var/tmp  overlay 931G  已用 696G  可用 229G     ← 磁盘
```

- 今天 `/tmp` 曾经 **100% 满（可用 0 KB）**，直接导致**派单被拒**与门禁**假红**；
- 内存 29G / 已用 20G / **swap 已用 28G** —— tmpfs 与内存是**同一个池**，所以「夹具把 /tmp 写满」与「OOM 杀掉整队」是同一件事的两面；
- 工具里 `TMPDIR` 已被引用 **427 处**，`tmp-hygiene.sh` 也认它（我在 `/var/tmp/teamsmith` 下实测 status 正常）——**机制已经在**，缺的是**默认值**。

## 要产出什么

一个 OpenSpec change（或足够小的提案），至少覆盖：

1. **解析顺序**：`$TEAM_TMP_ROOT`（新配置键，可空）→ `$TMPDIR` → 平台默认 `/tmp`；由**一个函数**给出（不许各处各算），并让夹具/清扫器/门禁/容器挂载**都走它**。
2. **默认建议**：Linux 上默认到 `/var/tmp/teamsmith-<项目 ns>`（磁盘、跨重启保留），**并说明为什么不是 `/tmp`**（本机 `/tmp` 是 tmpfs：写盘等于吃内存，且会被 OOM 与清理互相牵连）。
3. **容量前提绑定到选定根**：现有的余量地板（字节 + inode）必须**检查选定的那个根**，报错文案要**点名那个根**（今天它报的是 `临时根 /tmp 磁盘不足`，若配置换了根也必须跟着换）。
4. **清扫器**：按同一个根工作，命名与「占用/年龄」判据不变。
5. **迁移与回滚**：已有项目升级后**默认行为变化**要在 CHANGELOG 写清；给一条回滚（`TEAM_TMP_ROOT=/tmp`）。
6. **红侧**：① 把解析顺序改成「各处自己算」→ 夹具必须能发现（例如两处给出不同根时红）；② 把地板检查指向固定的 `/tmp` 而不是选定根 → 必须红（现场：选定的根很空、`/tmp` 很满时不许拒绝）；③ 选定根不可写/不存在 → **具名失败**并给修法，不许静默退回 `/tmp`。
7. **不变量**：夹具的**语义**（隔离、清理、年龄判据）不变；不改门禁的判定口径；容器里挂载仍是我们自己的根。

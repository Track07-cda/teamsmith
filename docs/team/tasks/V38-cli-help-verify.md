## 必须自己做的（不许只复跑作者脚本）

1. **逻辑类（门禁该有的）自证**：三级各自的入口可用；命令页与组页逐字节一致（`team help <cmd>` ≡ `team <cmd> --help`）；未知组与未知命令 exit 2 且点名；`--help` 不加载配置、不执行被帮助的命令、不启动进程；`--print`/`--json` 不受语言影响。
2. **Walk A 扩面**：`routes.sh` 现在读命令清单、把**每一级**的每条用法行喂真解析器；既有非空洞控制臂/承诺探针/翻转不动；给出改动前后覆盖的命令数（design 说 1 面/47 条/42 命令 → N 组页/48 命令）。
3. **语言的机制**：`TEAM_LANG` 缺省英文、`zh` 切中文、非法值可见告警后回退英文、缺键渲染可见标记（不是空白也不是崩）。
4. **承诺兑现**：命令清单里 `effect`/`auth`/`undo` 这些行为声明的取值有真探针（只读 → 状态指纹不变；needs-yes → 无授权拒绝；起进程 → 有记录；幂等 → 第二次不变；可撤销 → 指纹复原）；没有探针的取值判红。
5. **文本类由你读出来**（D170，评审把关不设门禁断言）：把**入口页、一个组页、两个命令页**的渲染样张（中英文各一份）通读，确认：菜单短小（三级、入口页不一次铺开所有命令）、排版有四级缩进、措辞讲普通话（PM/席位/工作树/任务书/category/change/spec/gate/ledger/pulse/knock/--yes 都有一句可读定义）、深度够（读完能答「干什么/什么时候用/读写什么/副作用/要不要 --yes/能不能撤」）。**发现一处不合格就记 FAIL**。
6. **文本类断言真被拿掉了**：确认「排版/概念/键集」这些不再靠门禁断言（作者报告说 `468 ✓ → 90 ✗0` 的差值就是移出门禁的文本类断言）——核对这个差值的构成是**移走的文本断言**，不是被削弱的逻辑断言。
7. **不削弱既有断言**：既有 routes Walk A/B、§51 的「承诺必须兑现」、help 的非空洞控制臂一条不动。
8. 容器纪律（钉死容器 + 干净 clone、先看 /tmp 余量）；任何「既有红」同命令对照 v0.2.0。

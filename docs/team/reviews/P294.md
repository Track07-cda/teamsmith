# P294 · **撤回**（前提不成立）

- 判定: **撤回（未做任何改动）**
- 我（PM）报的缺陷是「门禁锁记录陈旧」：记录写 `pid=599698`，而我的检查说那个进程不存在。
- **持有它的席位先取证再实现**：`pid=599698` 活着（`bash …/tests/smoke.sh`），而 `/proc/599698/stat` 的 `starttime=25584249` **与记录里的 `start=` 完全一致**；两个 pid 是**同一次运行的两层**（`flock` 包装层持内核锁、记录写 runner）。**我复核后确认它对**。
- **我的错误**：用 `awk -F'[= ]' '/pid=/{print $2}'` 解析 **TAB 分隔**的记录，取到字符串 `pid`，于是 `ps -p pid` 报「不在」。我把自己的解析 bug 当成了产品缺陷，并据此发了任务书与一条关键回复页——已在关键回复页发布更正，`docs/team/DECISIONS.md` D191 已标注撤回。
- **教训**：判「记录是否陈旧」要用**记录自己提供的判据**（`start` 对 `/proc/<pid>/stat` 的 starttime）——那是我在那条变更的 brief 里写下的判据。

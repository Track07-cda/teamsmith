## 二、这一版有什么（v0.3.4 之后 215 个提交、16 个已验收任务）

**行为变更（要在升级说明里点名）**

- `team say` 默认**立即直送**，`--now` 参数退休；有 inbox-watch 时仍走零按键通道，没有时才直送。失败与持有的项仍进 Outbox。
- 关键回复改为**标记捕获**：正常回答末尾带 `[[team-reply]]`，由插件捕获成编号回复；`team reply post` 退为手工回填。
  流式尾部帧会短暂显示标记（D214 接受，实测约 95–187 ms），最终回复、历史、页面与存储都不含它。

**其他**

- 通知：git 探测的 stderr 不再污染 Pi 输入（P381）；CI 改用最新 Pi 运行时并按版本解析（P380）。
- 指令瘦身（P400/P401/P403/P404）：AGENTS 受管块 167→112 行、PM 提示词 −2.4%、`SKILL.md` −18.8%；
  `team init` 只替换 Teamsmith 标记块，标记外逐字节不动（含 CRLF、末行无换行），歧义直接拒绝；
  空白契约时从既有配置渲染会话名与名册，不再用目录名与硬编码默认。
- 夹具与门禁：CI 分片夹具在数字 UID 下的红（P382）、面板窗口计数（P386）、关键回复滚动时机（P383）、
  隔离守卫范围（P399）、§2 段落依赖的 cwd（P405）；OpenSpec 统一到 1.16.0，门禁暂跑非 strict（D226）。
- 内部地基：CLI/Pulse/Pi 共用的项目状态权威（定位器 + 版本化快照 + flock 事务，P406）——**尚无任何提醒功能**。

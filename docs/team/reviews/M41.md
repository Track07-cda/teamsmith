1. **只读命令不拦**，但 sock 必须记**默认**（`act=pass · sock=/tmp/tmux-1000/default`）——不许把假隔离记成私有；

## Decisions and deviations

1. **`_default_sock` 是固定靶（`realpath(/tmp)/tmux-<uid>/default`），不再是「本调用算出来的那个 default」**。
   这是修 ③ 时发现的真 bug：先前的 WIP 把 `_default_sock` 从当次 `_tmpdir` 算，导致 `TMUX_TMPDIR=<已建私有目录>`
   的 kill-server 被误拒（M36 的「私有放行」会回归）。smoke ③ 钉住了这一条。
2. **`TMUX_TMPDIR=<普通文件>` 被保守重拒**（真 tmux 是直接报错、不会落到默认 socket）。shim 不能为了判定去
   `mkdir`（有副作用），也无法在 O(1) 里复刻 tmux 的「mkdir 成功或 EEXIST」判据；重拒不漏拒，文案与「不存在」
   分开（`不是目录` vs `指向不存在的目录`），实测矩阵把这个偏差写清楚了。
3. **没有做 `-S ""`/`-L ""` 的 given-ness 建模**（空值参数仍落入默认判定 → 保守重拒）。真 tmux 对它们会在
   `connect()` 处失败，到不了默认 server，所以重拒是安全方向的偏差；不影响本任务范围。
4. **两个 M28 前的证据包进 legacy 豁免**（V4.0/pkg/lib.sh、M9.3-dev2/pkg/run.sh，各 1 条 `/usr/bin/tmux -L $VAR kill-server`）。
   它们是冻结的审计记录，不能改内容；豁免按 sha256 + 条数校验、每轮打印，理由写在 `tmux-lint-legacy.txt` 里。
   M41 规则对 **tests/** 与今后的包照旧生效。
5. **`command tmux` 不算绕过**（PM 的补充约束里把它与绝对路径并列）：`command` 只跳过函数/别名，PATH 解析
   照旧，仍然命中闸门。文档与 lint 注释都写明了这一点；真正的绕过是字面绝对路径。
   另有一条**修不了**的盲区：变量里装绝对路径（`R=/usr/bin/tmux; "$R" kill-server`）静态看不出来 ——
   已写进 §18 与 lint 头部「已知边界」。
6. **CHANGELOG 未动**：M40/M41 都还没进版本段（v1.42.0 之后 release 还没做），按现状留给 PM 的发布步骤。
7. **闸门的固定开销**（实测，卡片层 200 次调用取平均）：pre-M41 shim 12.0 ms/次 → 本分支 shim 14.8 ms/次
   （+2.8 ms；多的是 `realpath -e` / 目录判定的子进程）。闸门只注入 PM 与 worker 窗口（`team_tmux_shim_exports`
   的三个调用点），pulse/panel 窗口不经过它，面板的 1% CPU 契约不受影响。

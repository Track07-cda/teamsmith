## 2. The generalization's exact rule (no per-shape conditions)

```
for every active change directory d under <root>/changes (archive/ excluded):
  1. if d is a symlink at all                              → <d>:1  delta-change-dir-symlink   and stop
  2. change_tree := readlink -f d ;  specs_tree := readlink -f d/specs
     unless specs_tree is at or below change_tree          → <d>/specs:1  delta-symlink-escape and stop
  3. for every delta df = find -H d/specs … -name spec.md:
     unless readlink -f df is strictly below specs_tree    → <df>:1  delta-symlink-escape   and skip that df
```

Three properties make this the end of the whack-a-mole rather than a fourth condition:

* **Every path is resolved, always** — not only the ones the previous rounds knew to be links. Step 3 has no
  `[ -L ]` test any more: a delta under a symlinked `specs/` root, or any future link shape in between, is judged
  by where the file really is.
* **The containment root is the change's own tree** — `specs_tree` is derived from `change_tree`, so a root that
  itself moved is caught at step 2 and step 3 compares against the root that was actually accepted.
* **Canonical operands only** — both sides come from `readlink -f`; the tests are `sl_within` /
  `sl_within_or_eq`, i.e. string-prefix checks with a `/` separator, so `[`, `*` and `?` in a path cannot defeat
  them, and an unresolvable path is a refusal, not a free pass.

The two codes are the two refusals the archiver itself makes for this family; a shape the archiver accepts stays
green (the `specs/ → real-specs` control and the 44-shape matrix).

# P390 · PM review of immediate-by-default `team say` exploration

Candidate: `ec78b6c622ad` · verdict: **ACCEPTED AS EXPLORATION — Propose only**

The report identifies the minimal behavior change and an important implementation trap: the old explicit `say --now` force branch runs before inbox-watch routing, so simply changing `now=0` to `1` would bypass the existing zero-key channel. The accepted interpretation of D207 is therefore **watch-first, immediate tmux fallback**: a live valid watcher keeps durable inbox + spool delivery with zero keys; otherwise a running, safe target gets the old forced send behavior by default. The public `say --now` flag is removed, not retained as an alias.

This preserves the user's immediacy decision without regressing the watched channel. It does not reopen the draft-semantics vote and does not broaden the change to notify, meeting, Pulse, draft send or `outbox flush --now`.

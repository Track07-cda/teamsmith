## 决策 / 偏离（需要 PM 知情）

1. **`open-focused` 的视图是 B3 的**：App 里 `detailId` 状态 + 打开动作已经落地（键位带 chip、Enter、点焦点卡），但**渲染详情视图属于 B3**。为了不让这个状态悬空，B2 就实现了规格里那条「详情打开时被替换的块不留目标」：`view.detail` 一旦有值，看板卡片**不再带点击目标**（smoke §28-h 与目标表断言覆盖的是关闭态）。B3 在这个缝上接视图即可。
2. **焦点落点规则**：`resolveFocus` 按 id 认；id 不在了 → **它所在车道的第一条**；该车道也空了 → **第一条非空车道的第一条**（spec 只写了前半句，后半句是我加的兜底，真 pty 夹具两条都测了）。
3. **滚轮 vs 跟随焦点**：车道窗口在「没有显式 offset」时跟随焦点；一旦滚轮/按键给了 offset，**offset 优先**（否则滚轮永远滚不动 —— 那正是 6.2 要的行为）。键盘移动焦点时由 App 把目标车道的 offset 推到能看见焦点。
4. **<100 列的滚轮**：单列分组档只有一个页面窗口，车道内滚轮滚动的是这个窗口（车道在该档不是一个列，"光标在哪个车道"退化为整页）——与 spec「one scroll window for the page」一致。
5. **顺手修的一处标签缺陷**：`boardStateText('dropped')` 以前落到 `default` 直接回显英文 `dropped`；现在映射到新增的 `taskDropped`（`已放弃`）——快照不变量就是这么抓到的。
6. **夹具旋钮**：`B3_STUB_BOARD_FILE` / `B3_STUB_DONE` / `B3_STUB_AGENTS` / `B3_STUB_RECENT` 都放在 `tests/panel-b3-stub.sh`（agent:dev 所有），默认输出与旧夹具逐字节一致（B2 这轮又逐块核过一次）。
7. **`panel-cpu.sh` 加了 `TEAM_PANEL_CPU_PAGE`**（默认空 = 旧行为），否则「CPU 红线停在第四页」没有可复跑的入口。

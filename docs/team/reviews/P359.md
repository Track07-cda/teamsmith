`tmux-lint.pl:111` 原来按 `m{/(__pycache__|node_modules|logs|snapshots)/}` 排除——**任何**含 `logs`/`snapshots` 段的路径都不扫，且不打印跳过理由。两个后果都真：`tests/logs/probe.sh` 里的裸 `tmux kill-server` 永远不会被发现（判「干净，扫描 0 个脚本」）；把临时根挂到名为 `logs` 的目录下，37 个自检夹具全部消失（这是我 2026-10-22 那次四小时发布门禁作废的直接原因）。

改法：只保留生成物目录（`__pycache__`/`node_modules`）。改前先量：真树 105 个候选文件里被这两段排除的是 **0** 个，所以原本被判的文件一个都没少判；改后 `tests/logs/` 与 `tests/snapshots/` 的探针都红并点名。

独立验收（V92）：同一棵树上「红 → 绿 → 再红」、两版 `--list` 逐字节相同（181 行 / 64 脚本 / 180 条命令）、三个 TMPDIR（含含 `/logs/` 的那个）都是 37/37，而同一路径换修前判定器是 19/37。

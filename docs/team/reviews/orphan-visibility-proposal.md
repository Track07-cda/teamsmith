## 判定

方案把我给的现象与边界都落成了可证伪的合同，且**判据的来源选得对**：

- **身份从进程自己身上读**（`/proc/<pid>/environ` 里的 `TEAM_MAIN_ROOT`/`TEAM_ROOT`/`TEAM_PROJECT`/`TEAM_SESSION` + tmux 写的 `TMUX`），**形状复用既有的 `team_agent_bin_path`**——于是「普查说它是席位」与「存活判据说它在跑」用的是**同一个定义**（它明确引用了「各写一份就是下一个假告警的温床」这条既有教训）。这条正是我在任务书里要的「不是名字像就算」。
- **它自己否掉了「按 `TEAM_ROOT` 存在」这个判据**：带身份的进程里还有面板、开发服务器、tmux server——所以判据必须是**身份 + 形状**两条。这个反驳成立。
- **跨项目只报总量、不点名**（用户要求 + 账本禁令）落成明文要求：只给计数与内存合计，**且合计标成下限 `≥`**（因为形状判据只认得本项目配置的 agent 形状，认不出别家的适配器）——「标下限」这个细节比我的要求更严谨，防止读者把总数当成精确值。理由也写对了：**这份读数是要被抄进本项目账本的**，所以不能带别人的 pid/项目名/席位名/工作树路径。
- **本项目的清理走新入口 `team reap`，且「无 pattern」**（只接受记录的 pid 或 `--orphans` 的计划；`--yes` 才动手）——这条直接回应了我们踩过的 `pkill` 误杀别人的事故。
- **读数只增、有界、只读、可关、不进面板**：新读数不改变既有读数的含义（我在任务书里要求的），并给了「关掉」的开关。
- **红侧覆盖了四个假阳性家族**：P103 的旧形状（命令行提到 agent 路径）、「不是当前窗口的 pane」、拿**默认 server** 的 pane 表比对（私有 socket 上的活席位会被误判）、以及「server 查询不到就算孤儿」——最后一条尤其对：查不到时应当**不判定**而不是猜。

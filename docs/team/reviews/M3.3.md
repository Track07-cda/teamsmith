## Decisions and deviations

1. **`count` 的语义变了（同一个字段）**：对日志块，改前是"整文件非空行数"，现在是"**读窗口内**的行数"
   （Pi 会话块同理：窗口内事件数）。这是有界读取的必然结果；为免静默，加了 `truncated` / `file_bytes` /
   `tail_limit` / `tail_bytes` 四个可见字段，并在 `references/agent-adapters.md` §4 写明。
   小文件（≤ 窗口）语义与改前**逐字节相同**。
2. **Pi 会话也加了界（超出任务书点名的 `logActivity`）**：同一个 `readFileSync` 缺陷同样存在于
   `readSession`（活动流一开就整读会话，几十 MB 会话就是几十 MB RSS），所以顺手用同一套原语修了：
   头部窗口 64KiB（取 `session` 头）+ 尾窗。已单独断言（r6：RSS 60MB、`count` ≤ 5000、尾部正确）。
   会话头若超过 64KiB 会退化成 `elapsed: ?`（graceful，已写进文档）。
3. **glob 不再静默丢弃非普通文件**：旧行为里 FIFO/设备/断链被 `isFile()` 过滤成「无会话」；现在它们进入
   候选并在读取端给出 `available:false` + 原因。**目录仍然 → `source=none`**（V3.0 e2 的行为不变，
   pkg d6 专门钉住）。副作用：通配符现在也能匹配**符号链接**（很多 CLI 会软链 `latest.log`），d8 钉住。
4. **FIFO「挂死」不是红的既有缺陷**：旧 glob 直接过滤 FIFO，所以旧代码不会挂死；「不挂死 + 说明原因」
   是**绿侧新增要求**（我放宽了候选集，就必须保证不再阻塞），A/B 里如实标注。
5. **旋钮的转发限制（没越界去改）**：`TEAM_AGENT_LOG_TAIL_BYTES` 由 monitor.mjs 自己读环境变量，
   但 `team monitor` 只显式转发 `TEAM_AGENT_LOG_GLOB`，所以在 `.pi/team/config.sh` 里必须写
   `export TEAM_AGENT_LOG_TAIL_BYTES=…` 才到得了子进程（普通赋值是 shell 变量）。任务书把可改文件限定为
   `scripts/monitor.mjs`，`cmd-watch.sh` 是 PM 的文件，所以我**只写文档、没动转发**；PM 若想让它像
   `TEAM_AGENT_LOG_GLOB` 一样"普通赋值就生效"，加一行转发即可。
6. **没动 `CHANGELOG.md`**：版本号/发布条目是 PM 的事（且 M3.2 在并行改文档），本任务的写权限里也没有它。
7. **没动 `common.sh` 的默认值清单**：同上（M3.2 正在改 `common.sh`，任务书明确禁止我碰）。所以

## 我实测过的 / 我没测的（limits）

1. **没塞真 GB 级文件**：本机 MemAvailable 3.6GB（zram 已用），我用的是 256MiB（任务书下限）+ 稀疏文件
   （尾部 1MiB 真文本，磁盘占用 1.1MiB）——RSS 结论建立在**代码只读窗口**这一点上（`count`/`truncated`
   也一起断言了），不是"GB 级实测"。Pi 会话用的是 3.5MB/20001 行。
2. **RSS 只在有 `/usr/bin/time -v` 的 GNU 环境成立**（本机 overlay/tmpfs 都在盘上；`/tmp` 是 tmpfs 所以
   scratch 默认放 `/var/tmp`）。没有 GNU time 时 pkg 会 `SKIP` RSS 断言（其余断言照跑），不会假绿。
3. **只测了 node 24.19.0**（本机没有 bun/tsx）：`openSync(O_NONBLOCK)`/`fstatSync`/`Buffer.subarray` 都是
   node 与 bun 都有的标准 API，但我**没有**在 bun 下实跑 monitor.mjs。
4. **`--once` / live 的两条真链路断言在没 tmux 的机器上会 `SKIP`**（c4/c4b）；本机有 tmux，实跑到的是
   真链路。纯逻辑的 c1/c2/c3 在任何机器上都跑。
5. **A/B 依赖 `4235d32` 这个提交还在**（作为红基线）。历史被重写时它会 `skip`（不影响 run.sh 退出码），
   可用 `M33_BASE_REF=<rev>` 指定别的基线。
6. 边界：`--log-tail-bytes` 只接受正整数，`0`/负数/非数字回默认 + 警告；`1e5` 这类可被 `Number()` 接受的
   写法按数字处理（没做严格十进制校验）。

# 为什么有这份清单：M28 的 lint 要扫 `docs/team/reports/*/pkg/`（对抗性证据包），但 M28 之前的包
# 写在「tmux 隔离纪律」成型之前 —— 它们里的裸 tmux 调用不能就地改：那是别人验过的证据，改文件
# 等于动了账本。所以这些**文件**被显式豁免，豁免是**可审计**的：
#   * 按 sha256 冻结：文件内容一变（包括把裸调用修掉）→ 豁免自动失效，按普通文件重新判定；
#   * 条数记在下面，与实际不符 → 门禁红（baseline 过期，必须重新裁决）；
#   * 每轮门禁都会打印 `LEGACY <路径> ×N`（不静默）；
#   * `perl skills/teamsmith/tests/tmux-lint.pl --no-legacy` = 让它们全部报红（人工全面审计）。
# 新增/改动的证据包**不在**豁免范围：写新的 pkg 时，自己的 tmux 调用要带隔离证据（-L <私有名> 或
# env -u TMUX + 私有 TMUX_TMPDIR，或包一层隔离包装）。

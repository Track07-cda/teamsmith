# M28 tmux-lint 历史豁免清单（--write-legacy 生成，人工加了一条口径说明）
#
# 为什么有这份清单：M28 的 lint 要扫 `docs/team/reports/*/pkg/`（对抗性证据包），但 M28 之前的包
# 写在「tmux 隔离纪律」成型之前 —— 它们里的裸 tmux 调用不能就地改：那是别人验过的证据，改文件
# 等于动了账本。所以这些**文件**被显式豁免，豁免是**可审计**的：
#   * 按 sha256 冻结：文件内容一变（包括把裸调用修掉）→ 豁免自动失效，按普通文件重新判定；
#   * 条数记在下面，与实际不符 → 门禁红（baseline 过期，必须重新裁决）；
#   * 每轮门禁都会打印 `LEGACY <路径> ×N`（不静默）；
#   * `perl skills/teamsmith/tests/tmux-lint.pl --no-legacy` = 让它们全部报红（人工全面审计）。
# 新增/改动的证据包**不在**豁免范围：写新的 pkg 时，自己的 tmux 调用要带隔离证据（-L <私有名> 或
# env -u TMUX + 私有 TMUX_TMPDIR，或包一层隔离包装）。
#
# 格式：<sha256>  <未隔离条数>  <仓库相对路径>  # 理由
#
# ── 2026-10-17 · P308：清单已清空（当前 0 条豁免）────────────────────────────────────────────────

# 文件在当前历史里一条都不在（`git ls-files docs/team/reports | grep -c '/pkg/'` → 0）。它们只留在
# 改写前的旧历史里（`git merge-base --is-ancestor 914c334d HEAD` → 非祖先；`v1.19.0` 才含它），
# 也就是说当前树里没有任何可豁免的对象，每轮门禁都因此红在 `baseline —— …文件不在了`。
# 按本文件自己的规则「清单里的文件不在了（删文件就同时删豁免行）」删掉这 16 行：豁免的语义是
# 「不许就地改别人验过的**存在**的文件」，文件不在了就没有对象；从旧 tag 把证据包复活塞回当前树
# 等于把仓库改写时摘掉的账本内容重新发布，那不是测试基础设施该做的事。
